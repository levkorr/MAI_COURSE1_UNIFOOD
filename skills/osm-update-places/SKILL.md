# Обновление каталога заведений через OpenStreetMap MCP

## Выбор кампуса

Бери координаты из `UNIVERSITIES[university]['campus']` в `universities.py`. МАИ (`mai`) использует `places-cache.json`, МГСУ (`mgsu`) — `places-cache-mgsu.json`. Если кампус не назван, используй МАИ по умолчанию, как в приложении. Если запрошены оба кампуса, обрабатывай их независимо.

## Получение данных

1. Перед запросами прочитай исходные байты выбранного кэша через `original = places_source.read_snapshot(cache)`, где `cache` — объект `Path`. Используй эти байты для сравнения и последующей записи.
2. Для каждого из шести фильтров `scripts.audit_places.MCP_FILTERS` вызови `osmmcp.osm_query_bbox`. Передай объект `bbox` с числовыми полями `minLat`, `minLon`, `maxLat`, `maxLon` и один фильтр в `tags`, например `{"amenity": "cafe"}`. Отступы от центра обоих кампусов ±0.006° по широте и ±0.012° по долготе покрывают радиус поиска 650 м.
3. Собери словарь `responses` с ключами вида `amenity=cafe`. Значение — декодированный JSON успешного ответа из текстового блока MCP. Исправленная сборка возвращает `complete: true` и массив `elements`. Ошибку инструмента или неполный ответ можно повторить. Отсутствие `complete` означает, что сервер не подтвердил полноту. Для прежней сборки выполни `./scripts/build_osmmcp.ps1`, переподключи сервер и повтори выборку. Если получить подтверждение не удалось, сохрани текущий каталог и сообщи, какой запрос не прошёл.

## Сверка и запись

1. Из корня проекта вызови `scripts.audit_places.parse_mcp_catalogue(responses, campus)`. Функция проверяет полноту шести выборок, переводит строковый OSM ID в число, читает `location.latitude/longitude` у точек и `center.latitude/longitude` у линий и отношений, объединяет дубли и применяет штатный парсер. При конфликте данных или отсутствии геометрии проверь исходный ответ.
2. Сравни результат с `json.loads(original)` по OSM ID. Если файла ещё нет, исходный список пуст, а первый снимок требует полной выборки. Исчезновение известных мест, в том числе при пустой категории, проверь по тегам OSM и фильтрам приложения. При точечном запросе обновляй только выбранные места. Если запрошена только сверка, сообщи результат на этом шаге.
3. Для записи собери `updated` на основе исходного снимка, сохрани посторонние поля и укажи `source = "OpenStreetMap MCP / osm_query_bbox"`. При полной сверке выставь в `fetched_at` Unix-время окончания выборки, при точечном обновлении сохрани исходную метку. Вызови `places_source.replace_catalogue(cache, original, updated)`. При `CatalogueChanged` другой процесс уже записал новую версию. Прочитай её, заново получи данные и повтори сравнение перед записью. Ошибку сохранения сообщи пользователю.
4. Перечитай JSON, проверь кампус и состав записей. Сообщи число добавленных, изменённых и удалённых заведений, а также существенные пробелы в данных. Для адресов, расписания и доступности используй теги OSM. Фактическая работа заведения требует отдельного подтверждения.

`scripts/audit_places.py` подходит для воспроизведения прежней сверки МАИ из сохранённой выгрузки и при запуске перезаписывает кэш. Для актуализации и предварительной сверки используй свежие ответы MCP и шаги выше.

# Ревью переноса «Между парами» на UI Kit

## Объём и снимок

Проверена главная страница `/` целиком: планировщик, результаты и избранное, карта и её всплывающая панель, детали места и форма «Я здесь». Согласование объёма и UI Kit 1.0 зафиксировано в чате. Контракты API остались прежними.

- База `f31b144`, рабочая ветка `codex/ui-kit`. Префиксы SHA-256 проверенного содержимого: `app.py 4689E9F61805D49E`, `templates/index.html 475DEAA59C4B1579`, `static/app.js AAC1AE9DB3C45EBE`, `static/style.css 1264CCA07B9BB3C7`, `static/ui-kit/components.css 39FF61800B55B629`, `tests/mobile-verify.mjs B569CDC66B1ADFCB`. Остальные исходники UI Kit закреплены в [снимке 1.0](../ui-kit/index.md).
- Рабочая витрина: [сайт](http://127.0.0.1:5056/). Запуск из корня: `.venv\Scripts\python.exe -m flask --app app run --host 127.0.0.1 --port 5056`.
- Проверки приложения использовали Chrome, локальные каталоги МАИ и МГСУ, временную SQLite и точечную имитацию HTTP 503 для поиска. Ревью выполнено автором изменений. На этапе отчёта код не менялся.

## Вердикт и покрытие

Проверенная миграция использует общие стили и утверждённые компоненты UI Kit. В исходниках проверены импорты, 12/4-колоночная сетка, общие поля и кнопки, статусы, карточки, Lucide, фокус и модальные поверхности. Стили продукта используют утверждённые токены при оформлении Leaflet. Картографическое поведение и схемы остаются в Leaflet.

- Штатный Chrome-сценарий прошёл на 320, 375, 430 и 1280 px. Проверены список и карта, размеры областей нажатия на мобильном, детали и диалог, переход к метке, всплывающая панель и масштаб, смена вуза и времени, план на завтра, сохранение и отмена, фильтр избранного, сохранение выбранных параметров и отсутствие JS-исключений.
- Дополнительно проверены цвета интерфейса, использование стилизованного списка в Chrome, сохранение цвета выбранного фильтра при наведении, состояние загрузки, показ ошибки и восстановление после повтора, отправка формы «Я здесь» и сообщение об успехе. Всё выполнено на тестовых данных.
- `node --check static/app.js`, 14 тестов Python и `git diff --check` прошли.

## Разрывы и ограничения

**MAP-01 — читаемость меток в общем масштабе.** На десктопе и мобильном близкие места перекрывают друг друга. Видно на [снимке карты](evidence/mobile-map.png). Утверждённый UI Kit задаёт статусные цвета и области нажатия, правила группировки картографических меток в нём отсутствуют. Возможное развитие — согласовать группировку или сокращённый вид меток для общего масштаба. Изменение потребует отдельного решения.

**CHK-01 — повторяемость проверки всплывающей панели.** Один комбинированный прогон после съёмки снимков завершился по тайм-ауту ожидания всплывающей панели. Отдельный штатный сценарий на том же снимке прошёл. Ручной прогон со скринридером, другие браузеры и физические устройства в покрытие не вошли.

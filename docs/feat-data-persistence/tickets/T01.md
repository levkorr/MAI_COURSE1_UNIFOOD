Выделить подготовку схемы из `report_database()` в `app.py` в общий код. Поддержать абсолютный `REPORT_DB` при обычном запуске и команду `python -m database init <абсолютный-путь>` для первого развёртывания. Команда создаёт рабочую схему и отказывается открывать существующий файл для изменений.

Приёмка: отсутствующая явно заданная база останавливает запуск и не создаётся, инициализация создаёт пустые таблицы, повторный вызов сохраняет существующий файл, запуск с подготовленной базой успешен. Проверить через отдельные процессы и временный путь.

Описать в README первичное создание, перенос через SQLite Backup API и обновление приложения с прежним постоянным томом. Использовать API Flask и временные файлы для проверки оценок и планов после перезапуска и при открытии старой схемы.

Приёмка: действующая `mp-visitor` даёт доступ к прежнему плану, новый посетитель получает отдельную cookie. Срок оценки, интервал плана, замена и отмена проверены. Старые записи сохраняются, повторное открытие не дублирует оценки. Выполнить обязательные проверки Basic.

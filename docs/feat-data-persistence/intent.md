# Сохранение данных

- Slug: `data-persistence`
- Revision: 2
- Status: accepted
- Accepted revision: 2
- Решение пользователя: узнавать пользователя по cookie и сохранять оценки и планы при обновлении приложения.

Оценки загруженности и планы уже записываются в SQLite (`reports.sqlite3`). Путь к БД задан рядом с `app.py`. Избранное хранится в `localStorage`, а каталог заведений — в JSON-снимках OpenStreetMap.

## Согласованный объём

- **O1.** Для одного экземпляра Flask разместить базу оценок и планов по настраиваемому пути на постоянном диске. После перезапуска или обновления приложения с тем же диском прежние записи доступны с учётом действующих сроков отображения.
- **O2.** Существующая база открывается новой версией приложения с сохранением записей. Проверка выполняется на копии базы.
- **O3.** После обновления тот же браузер с действующей `mp-visitor` видит свой план и может его изменить или отменить. Другой браузер получает отдельный идентификатор.

В этом варианте избранное и каталог остаются вне объёма задачи. SQLite предлагается для одного экземпляра. При нескольких экземплярах с общими данными стоит рассмотреть PostgreSQL.

# Правила UI Kit

| ID | Правило | Источник |
| --- | --- | --- |
| COL-001 | Цветовые роли ссылаются на пять шкал от 50 до 950. Отдельная вторичная шкала не требуется. | [Токены](../../static/ui-kit/colors.css) |
| COL-002 | Основное действие использует Whipped Butter и более насыщенные ступени для наведения и нажатия. Текст и выбранное состояние используют Cookie Crumble. Фон страницы светло-кремовый. | [Токены](../../static/ui-kit/colors.css) |
| COL-003 | Успех, предупреждение и ошибка используют оливковые, янтарные и кирпичные пары с текстовым обозначением. | [Образцы статусов](http://127.0.0.1:5056/ui-kit#colors) |

| ID | Правило | Источник |

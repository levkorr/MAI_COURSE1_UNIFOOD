# Каталог компонентов

Ревизия 1.1, набор и состояния утверждены пользователем. [Живые образцы](http://127.0.0.1:5056/ui-kit#components), [шаблон с примерами](../../templates/ui-kit-components.html), [правила](rules.md). Для стилей подключите [компоненты](../../static/ui-kit/components.css), [взаимодействие](../../static/ui-kit/interaction.css) и согласованные основы. Примеры находятся внутри областей `kit-colors`, `kit-interaction`, `kit-sizing`, `kit-surfaces` и `kit-type`.

| ID | Компонент и применение | Варианты и состояния |
| --- | --- | --- |
| CMP-001 | `<button type="button" class="kit-action kit-surface-control">Открыть</button>` | Основная и вторичная (`kit-action--secondary`), фокус, наведение, нажатие, `disabled`, загрузка с `aria-busy`. Для переключаемой кнопки используется `aria-pressed`. |
| CMP-002 | `<a class="kit-link" href="#details">Подробности</a>` | Навигация, подчёркивание, наведение, нажатие, клавиатурный фокус. |
| CMP-003 | `input` или `select` с `kit-input kit-surface-control` внутри `kit-field`. | Связанная подпись, необязательное пояснение, фокус, ошибка и недоступность. Текст ошибки привязывается через `aria-describedby`. |
| CMP-004 | `<label class="kit-choice"><input type="checkbox"> Показать</label>` | Флажок или радиокнопка. Выбрано, не выбрано, недоступно и фокус. Для групп — `fieldset` и `legend`. |
| CMP-005 | `<span class="kit-badge kit-feedback">Черновик</span>` | Нейтральная, успех, предупреждение, ошибка. Статус передаётся текстом. |
| CMP-006 | `<div class="kit-notice kit-feedback kit-feedback--warning">Проверьте данные.</div>` | Успех, предупреждение, ошибка. Для динамических сообщений применяются INT-003 и подходящая роли сообщения семантика. |
| CMP-007 | `<div class="kit-card kit-surface-card">Содержимое</div>` и `<hr class="kit-divider">`. | Карточка с адаптивными отступами, семантический разделитель. |
| CMP-008 | `{{ place_card(name, meta, status) }}` из [общего шаблона карточки](../../templates/ui-kit-place-card.html). | Без оценок, с оценкой и с сохранённым планом. Избранное обозначается через `aria-pressed`. Название и «На карте» запускают действия. |
| CMP-009 | `{{ check_in(place) }}` из [общего шаблона окна](../../templates/ui-kit-check-in.html). | Нативный диалог и четыре плитки. На узкой ширине два ряда. Выбор выделяется цветом и сохраняет клавиатурный фокус. Отправка доступна после выбора. |

Для выпадающего списка добавьте `kit-select` к классам CMP-003. При поддержке `appearance: base-select` меню использует поверхность всплывающей панели, выбранный пункт выделен, фокус виден. В остальных браузерах раскрывается системный список. [Обновлённый образец](http://127.0.0.1:5056/ui-kit#component-select).

## Требования и поведение

- **R1.** На 320, 375 и 430 px обе вкладки уложились в экран. Основные элементы управления имеют высоту не менее 44 px. На ширинах до 390 px поля планировщика занимают отдельные строки.
- **R2.** По умолчанию виден список. Переключение сохранило вуз, время, дату и фильтр.
- **R3.** Касанием открылись карточка, диалог отметки и всплывающее окно маркера. «На схеме» показало выбранное место. Масштабирование, сохранение и отмена плана прошли.
- **R4.** На 1280 px сохранились две колонки, переключатель скрыт. Фильтр и параметры пережили смену ширины. Python-тесты прошли.

## Стандарты и корректность

Переключатель использует штатные кнопки и сообщает выбранное состояние. Скрытая карта не пересчитывается по нулевой ширине. При первом показе она вписывается в доступное пространство, после чего действие «На схеме» может переместить карту к месту. CSS ограничивает мобильные правила диапазоном до 730 px. Данные, API и схема SQLite не менялись.

Блокирующих замечаний нет. Обзор выполнен отдельным проходом тем же исполнителем.

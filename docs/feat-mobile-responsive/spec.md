# Спецификация адаптивного интерфейса

revision: 1
status: accepted
accepted_revision: 1
intent: intent.md, revision 1

Пользователь подтвердил спецификацию и реализацию в чате.

- **R1 → O1.** До 730 px включительно элементы планировщика, фильтры, карточки и диалоги укладываются в ширину окна. Основные кнопки и поля имеют область касания от 44 px. Длинное название места переносится. Высокий диалог прокручивается внутри экрана.
- **R2 → O2.** При первом открытии на смартфоне виден список. Кнопки «Список» и «Карта» показывают соответствующие области и сообщают выбранное состояние через `aria-pressed`. Переключение сохраняет выбранный вуз, время и фильтры.
- **R3 → O2.** Действие «На схеме» открывает карту и выделяет место. При показе Leaflet обновляет размер. Масштабирование, маркеры, диалог заведения и операции с планом работают в обоих режимах, где доступны соответствующие действия.
- **R4 → O3.** От 731 px одновременно видны список и карта, переключатель скрыт. Изменение ширины окна не сбрасывает параметры поиска. Flask API, данные и хранение планов сохраняют текущие контракты.

Шаблон задаёт элементы управления, CSS отвечает за компоновку и видимость, JavaScript связывает выбранный вид с существующей картой Leaflet. Обе области используют общий набор результатов и существующие обработчики. Дополнительные страницы и миграции не нужны.

На локальном Flask проверить ширины 320, 375, 430 и 1280 px. На мобильных ширинах проверить отсутствие горизонтальной прокрутки и видимость элементов. Пройти переключение, выбор вуза и времени, открытие карточки, поиск места на карте, сохранение и отмену плана на завтра. На десктопе проверить обе колонки и фильтры. Выполнить команды Basic из профиля проекта.

## Проход 1. Намерение и требования

**Вердикт — ручная сверка по новой инструкции не проходит.** Подтвердить соответствие исходному намерению целиком нельзя. Проверены заявленные в инструкции результаты и опубликованное в README поведение.

1. **P1. Преобразование формата MCP пропущено.** Шаги 1–2 раздела «Сверка и запись», строки 20–21, передают результат в `parse`. У сохранённой точки MCP строковый `id` и координаты `location.latitude/longitude`. У линий и отношений сервер выдаёт `center.latitude/longitude`. Парсер ожидает числовой ID и поля `lat/lon`. На штатной точке МАИ воспроизведён `KeyError('lat')`, после одного переименования координат — `TypeError` при `id % 55`. Для выполнения сверки опишите преобразование ID и координат обоих типов перед вызовом парсера. [Инструкция](../../skills/osm-update-places/SKILL.md#сверка-и-запись) · [Парсер, строки 56–78](../../places_source.py#L56)
2. **P2. Признак неполной выборки теряется до проверки.** Шаг 3 раздела «Получение данных», строка 16, полагается на видимые признаки ошибки, включая `remark`. В используемой сборке `osm_query_bbox` декодирует только `elements` и возвращает новый объект только с этим полем. Ответ Overpass HTTP 200 с данными и сообщением о тайм-ауте выглядит успешным. Если пропущено новое заведение, сравнение с прошлым каталогом тоже не выявит пропуск, а шаг записи обновит `fetched_at` всего каталога. Для полной сверки нужен путь получения данных, сохраняющий признак ошибки. Доказательство — локальный исходник сборки `0916a0b`, `pkg/tools/osm_query_tools.go`, строки 236–258 и 284–291. [Инструкция](../../skills/osm-update-places/SKILL.md#получение-данных) · [Версия сборки в проекте](../../scripts/build_osmmcp.ps1#L2)

## Проход 2. Стандарты и корректность

**Вердикт — загрузчик может потерять уже сохранённые данные.** Пункты 3–6 воспроизведены через `get_places` или Flask API с временным файлом кэша.

3. **P2. Фоновая запись затирает более свежую ручную сверку.** В строке 114 загрузчик безусловно выполняет `replace`. Если ручная сверка запишет результат после начала фонового запроса, завершающийся поток подменит файл целиком. В проверке ручная запись `node/4` с меткой 300 сменилась на `node/3` с меткой 200. Предварительная проверка в ручной инструкции защищает только её собственную сторону записи. Нужна согласованная проверка версии снимка у обоих писателей при замене. [Загрузчик](../../places_source.py#L114) · [Правило записи в инструкции, строка 22](../../skills/osm-update-places/SKILL.md#сверка-и-запись)
4. **P2. Резервный XML удаляет известные заведения типа `relation`.** После отказа обоих Overpass строки 99–101 принимают любой непустой результат XML за свежий. XML-парсер пропускает отношения. Снимок и резервный ответ содержали `node/1` и `relation/2`. На диск попала только `node/1`, а загрузчик вернул `stale=False`. До изменения при доступном кэше и двух отказах Overpass сохранялся прежний снимок. Резервная ветка должна поддерживать эти объекты либо сохранять пригодный кэш при неполном результате. [Загрузчик](../../places_source.py#L99) · [Разбор XML](../../places_source.py#L37) · [Поведение при сбое](../../README.md#карта-и-заведения)
5. **P2. Разовый отказ запуска потока выключает обновление кампуса до перезапуска процесса.** Строки 152–153 записывают `inf` до вызова `Thread.start()`. При отказе запуска `GET /api/places` ответил 503 при наличии пригодного кэша. После восстановления следующий запрос вернул 200 со старым снимком, число попыток создать поток осталось нулевым. При отказе запуска нужно вернуть снимок и назначить конечный срок следующей попытки. [Планирование обновления](../../places_source.py#L152) · [Обработка в API](../../app.py#L118)
6. **P2. Ошибка записи скрыта от вызывающей стороны.** Строки 115–121 поглощают `OSError`. При `PermissionError` на замене файла синхронный вызов вернул новые записи с `stale=False`, на диске остался старый каталог. Фоновая задача отбрасывает возвращённые данные, и последующие посетители продолжают получать старую версию. Ошибку сохранения нужно передать вызывающему коду или явно зарегистрировать в фоне. [Запись кэша](../../places_source.py#L115) · [Обещание сохранять снимок](../../README.md#карта-и-заведения)

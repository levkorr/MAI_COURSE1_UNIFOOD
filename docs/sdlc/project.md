## Проверки

| Проверка | Предложение | Команда или сценарий | Состояние |
| --- | --- | --- | --- |
| Синтаксис JavaScript | Обязательная | `node --check static/app.js` | Прошла на исходной версии |
| Проверка типов | Не требуется в согласованном профиле | В репозитории нет настроенной проверки типов | Не требуется |
| Тесты Python | Обязательная | `.venv/Scripts/python.exe -m unittest discover -s tests -q` | 11 тестов прошли на исходной версии |
| Браузерная проверка | Обязательная для изменений интерфейса | Проверить ключевые сценарии задачи на локальном Flask-сервере | Сценарии уточняются в спецификации |
| CRAP и мутационное тестирование | Не требуются в согласованном профиле Basic | — | Не требуются |

Для локального запуска нужны Python с зависимостями из requirements.txt, Node.js и браузер.

## Доставка

Проверки Basic выполняются локально и в GitHub Actions. Workflow `CI` запускает проверку `Application and browser tests` для PR и при обновлении `main`. Браузерный сценарий запускается командой `node tests/mobile-verify.mjs` с Chrome, сохранёнными каталогами и временной SQLite. Целевая ветка — `main`. Публикация PR и слияние определяются разрешением на конкретную задачу.

## Пробелы настройки

Открытых пробелов по профилю Basic нет. Критерии браузерной проверки определяются для каждой задачи.

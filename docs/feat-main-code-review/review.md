## Проверки и ограничения

- На обычном изолированном запуске прошли 22 теста Python, проверка синтаксиса JS приложения, примеров UI Kit и браузерного сценария. Chrome прошёл сценарии на 320, 375, 430 и 1280 px, включая отправку оценки, фильтры, выбор вуза, сохранение и отмену плана. Главная страница, четыре маршрута UI Kit и все 22 локальных ресурса, на которые ссылается их HTML, ответили HTTP 200. [Тесты](../../tests) · [CI проверенного коммита](https://github.com/levkorr/MAI_COURSE1_UNIFOOD/actions/runs/46075738150)
- В сохранённых каталогах 34 уникальных ID МАИ и 6 МГСУ. Проверки отказов использовали временные файлы и базы. Для проверки запоздалого ответа в Node исполнен обработчик приложения с управляемой задержкой, сортировка и потеря фокуса проверены отдельно в Chrome.
- В локальном исходнике osmmcp с применёнными патчами успешно прошли Go-тесты пакетов `core`, `osm`, `server` и оба специализированных теста `TestNearbyCafeAlternativesAndBuildingCenter` и `TestBBoxCompleteness`. Применение самого патча к чистому исходнику на Windows проверялось отдельно.
- Проверка OSM относится к данным в Git, локальным снимкам геометрии, воспроизведению загрузки и протоколу локальных процессов. Фактическая работа заведений, доступность публичных зеркал в момент ревью, физические телефоны и другие браузеры в этот прогон не входили.
